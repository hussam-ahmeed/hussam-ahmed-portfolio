# Hussam Ahmed Portfolio Website

A lightweight personal portfolio website built with HTML and CSS to present a background and interest in cybersecurity.

## Features

- Static HTML page
- Custom CSS styling
- Image assets for the portfolio presentation
- Suitable for deployment through GitHub Pages

## Technology

- HTML5
- CSS3

## Project structure

```text
.
├── index.html   # Main page
├── style.css    # Site styling
└── images/      # Visual assets
```

## Run locally

Clone the repository:

```bash
git clone https://github.com/hussam-ahmeed/hussam-ahmed-portfolio.git
cd hussam-ahmed-portfolio
```

Open `index.html` in a browser, or start a local static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
